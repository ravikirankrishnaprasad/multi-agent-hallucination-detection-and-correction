# Multi-Agent Hallucination Detection and Correction System

This repository contains the implementation accompanying the MSc dissertation
submitted to Liverpool John Moores University.

## Overview
The project proposes a multi-agent framework for detecting and correcting
hallucinations in generated responses using evidence grounding and verification.

## Datasets
- MedHallu (medical hallucination benchmark)
- TruthfulQA (truthfulness evaluation benchmark)

Due to licensing and size constraints, datasets are not included in this repository.
All preprocessing steps are fully reproducible.

## Project Structure
- scripts/ – data processing, verification, correction, experiments
- results/ – summary metrics and figures
- indices/ – retrieval indices (excluded from version control)

## Reproducibility
The dissertation implementation is frozen under:
**Git tag: v1.0-ljmu-dissertation**

## Large Artifacts
Per-sample experiment logs are excluded from version control due to size constraints.
Summary metrics and figures required for reproduction are included.
